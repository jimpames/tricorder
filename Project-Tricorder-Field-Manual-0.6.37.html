Horizon, G-meter, GPS speed, baro altitude proxy, satellites, stars, SOL orbits, moon phase, GNSS clock, and HF forecasts MUST NEVER be used to fly, land, or navigate any craft. The satellite clock is a field novelty, not a time standard. This load is not DO-178C airborne software.

Face

I Inquiry · II Sensor · III Sentry (continuous default) · IV Audio · T / XLATE Translator · H Horizon · S Sat/Stars · O Sol (space → earth weather → moon → off) · L E V P logs · IPL / ALL abort · STT kill speech.

ROBO four-state cycle: dark = Kokoro · green ROBO = Android robot voice · yellow [H/F R] = robot + hands-free top-level listen · red [MUTE] = silent observer (CRT and log only, no voice, no alert tones). Next touch returns dark / Kokoro.

Spoken overlays: SETTINGS, BACK END / BACKEND / CAMERA, HELP, DIAGNOSTICS, COMPUTER, CLOCK, DICTATION, and the TRICORDER … menu.

0.6.37 — CRT stack and cattle

Detector bars on Audio / Sensor / Sentry now stack weakest on top, HIGHLY LIKELY on the bottom of the CRT so the green winner stays in frame after auto-scroll. Wrapped labels no longer hide the lead bar.

Bucket bug: the linker used \bcat, which matched YAMNet’s Cattle, bovinae. Mooing therefore painted as CAT. Cattle / moo / cow is its own bucket; cat only matches cat / cats.

0.6.36 — flight readings isolation

By-airframe / by-tail timelines were walking neighboring YAMNet lines (Silence, Speech) because every listen wrote a field-log row and the bar used file-line index.

Fix: a flights bar only accepts kind=flight (or a flight/context row with tail/type). Playback is by log id, not “next line.” Raw listen noise (Silence, Speech, Quiet) stays in the audio log and is not a field-log event unless BirdNET named a bird.

Old mixed rows remain in the book. New overheads chart clean.

0.6.34–0.6.35 — live detector and LED meter

TOP 3. Audio, Sensor, and Sentry keep the raw percent list. Scroll the CRT up for it. Under that list a fused TOP 3: same family collapses (barred owl + hoot → owl). #1 HIGHLY LIKELY glows green when it leads; other possibles yellow; junk tails red. Charts refresh every listen/scan. Auto-scroll parks the phosphor on the bars.

LED. Scroll text is #1 LABEL 72%. Right-hand vertical tube: 0% bottom, 100% top. Fill is solid below the reading, outline only above it. Amber pointer on the live percent. Heading/ACC chatter does not overwrite that while a detection is live.

Readings drill. Top chart is still HUMANS / VEHICLES / FLIGHTS / …. Touch a bar for that category’s sub-bars and its log timeline. BACK returns to the summary. Flights: By tail and By airframe. Photo on a flight row opens the airframe card. FROM/TO open the city dossier.

Overhead set. A pinned flight card also shows a small queue chart of tails and types already in the overhead set (up to several concurrent hits).

0.6.33 — MUTE

Fourth ROBO state. Red [MUTE]: no Kokoro, no robot voice, no klaxon/chime. Screen and field log still write. Silent observer / camp unit that must not announce itself. Next touch returns Kokoro (dark).

0.6.32 — hands-free TRICORDER menu

Yellow [H/F R]: say the ship name first, then the function. Leave a mode with the face button.

Commands: TRICORDER SENSOR · AUDIO · SENTRY · TRANSLATOR / TRANSLATE · HORIZON · SATELLITES · SOL · CLOCK · DICTATION · SETTINGS · BACK END · DIAGNOSTICS · SUMMARIZE READINGS · HELP.

While yellow, speech that is not a TRICORDER line is ignored. Audio, translator, clock, and dictation own the microphone while they are up. Aliases include “trick order” and “tric order.”

0.6.30–0.6.31 — satellite clock, moon, places

CLOCK. Say CLOCK or TRICORDER CLOCK. Analog or digital, 12- or 24-hour. After the face opens: analog, digital, twelve hour, twenty four hour, timer coffee five minutes, cancel timer coffee, cancel all, explain, terminate.

GNSS lock uses Android GnssClock (GPS TimeNanos minus full bias minus bias, leap seconds to UTC). Display 4 Hz; hardware epoch ~1 Hz interpolated. Fold 3 open-sky uncertainty is typically tens to a few hundred nanoseconds — field clock, not a standard. Until lock, device wall time. Field-log timestamps stay ordinary milliseconds.

Moon. Sol cycle: space weather + orbits + HF/VHF/UHF → local earth forecast (six hours + three-day outlook, scroll) → moon phase → off. Voice MOON / MOON PHASE walks Sol to the moon panel.

Places. Logs, sensed events, and the horizon carry city/state when Geocoder has it, plus an offline Open Location Code (plus code). Optional what3words key in settings. Raw lat/lon still stored.

0.6.28 — MEDICAL extracts, pinned airframe, city BACK

MEDICAL. WikiMed is a title catalog. Body and photographs from English Wikipedia. Say medical pink eye.

Pinned airframe. Overhead card stays until DISMISS AIRFRAME. Audio may still speak alerts; it does not steal the picture.

City BACK. FROM / TO opens the city dossier. BACK TO AIRFRAME returns the same craft photo.

0.6.26–0.6.27 — flights + knowledge banks

Overhead card. OpenSky + adsbdb type/owner/tail. Photo: Planespotters, airport-data, JetPhotos. JPEG in the field log. Touch photo for airframe facts. Touch FROM/TO for city dossier.

One-shot: memory alpha Airbus A320. Bare bank name opens the prompt and arms the mic. TERMINATE closes. MEMORY ALPHA is Simple English Wikipedia, cached on device. No 30 MB illustrated ZIM is shipped.

0.6.22–0.6.25 — readings

SUMMARIZE READINGS [vehicles|flights|birds|…] [day|week|month|all]. Letter bars A B C, QTY, color legend. Touch a bar for that category’s timeline. Day/Week/Month/All chips live.

TTS length slider 400–8000. Unit does not classify its own speech as humans detected while talking.

Dictation (0.6.15–0.6.21)

Wake: dictation or TRICORDER DICTATION. NEW · EDIT nnnn · LOG nnnn (CONFIRMED) · SUMMARIZE nnnn · MINDMAP keyword · SPEAK nnnn · KILL nnnn (CONFIRMED) · TERMINATE. ZULU then SAVE or ABORT.

Buffer: CURSOR MINUS / PLUS word · BACKSPACE · NEWLINE · CUT / CUT WORD · PASTE · HOME / END. PUNCTUATION PERIOD (also bare PERIOD / DOT).

Watch / IPL (0.6.9–0.6.14)

Sentry captions every dwell. Sure weapon: klaxon + WEAPON DETECTED x3. Possible weapon: chime. Motion does not gate.

Audio priority: gunfire x3 + klaxon; scream; siren x3; air/rail/ship; vehicles; named animal; humans x3; entertainment. Fireworks can look like gunfire.

IPL aborts in-flight work. Kokoro slider kills speech. Text over 80 characters is chunked.

SOL / sky / horizon

O Sol cycles space + HF/VHF/UHF, earth forecast, moon phase, then off. S toggles satellites and stars. Horizon shows heading, G, GPS speed, baro altitude proxy, and place line. All of it is a toy. Not for flight.

Backends

Termux four-pack on loopback: chat :8080, vision :8081, image :8188, tts :5000. Launch with ~/bin/tricorder start. Image sliders: steps and size (256 / 384 / 512). See TERMUX-BACKEND-INSTALL.md in the source tree.

On-device packs (APK, no Termux): YAMNet, optional BirdNET fetch, flora/fauna fetch, translator language packs. First-boot will pull missing packs when Earth link exists.
